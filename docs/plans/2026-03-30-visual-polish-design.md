# 视觉打磨蓝图 — 霓虹像素风格

> 生成日期: 2026-03-30 | 分支: claude/migration-44items
>
> **风格定位**: 霓虹像素 (Neon Pixel) — 暗色背景 + 发光元素 + 粒子氛围
>
> **原则**: 不重做美术资产，只用动画/粒子/shader/过渡提升感知品质
>
> **参考**: Infinitode 2 的简约科技感 + Kingdom Rush 的动画打磨度

## 分层结构

```
Tier 1: 核心反馈 ——— 死亡/命中/射击（玩家每秒看到数十次）
Tier 2: 节奏演出 ——— 波次/Boss/胜败（每局看到数次）
Tier 3: 氛围层 ——— 环境粒子/背景层次/标题画面（持续感受）
Tier 4: 交互细节 ——— 建塔/卖塔/升级/UI 动画（操作时感受）
Tier 5: 进阶品质 ——— 弹道朝向/塔外观/地形装饰（长期打磨）
```

---

## Tier 1: 核心反馈

### 1.1 敌人死亡动画

当前：精灵瞬间消失 + 粒子爆散。

方案：死亡时进入 0.3s 的 dying 状态（不立即移除）：
- 精灵 scale 1.0 → 0（ease-in 缩小）
- alpha 1.0 → 0
- 向上微移 5px
- Y 轴轻微旋转晃动（±15° 摆动一次）
- DeathBurst 粒子在缩小开始时触发
- Boss 死亡：先膨胀 1.2x 再缩小（0.5s）+ 屏幕白闪 0.1s

实现：Enemy 加 `DyingTimer`，pool.Kill 设 DyingTimer 而非立即 Active=false。DrawEnemies 对 dying 状态应用变换。

### 1.2 敌人命中反应

当前：hit 帧资源存在但未使用。

方案：
- 命中时切换到 hit 动画（2 帧，0.12s），然后恢复 walk
- 精灵闪白 1 帧（ColorScale 全白叠加，alpha=0.6）
- 重击（伤害 > maxHP 的 20%）：额外微推后退 2px + 弹回（0.1s）

实现：anim.Animator 的 PlayOnce("hit") + 回调恢复 walk。HitFlash 用 Enemy 已有字段。

### 1.3 塔射击强化

当前：0.15s 缩放脉冲，蓄力塔有辉光。

方案：
- 所有塔射击触发 MuzzleFlash 粒子（4 粒子沿射击方向）
- 射击瞬间精灵 ColorScale 提亮 20%（1 帧）
- 激光/光束：起始端白色辉光点
- 快速射击塔每 3 发加极微屏幕震动（strength=0.5）

## Tier 2: 节奏演出

### 2.1 场景过渡

当前：硬切，无过渡。

方案：统一 Transition 系统在 scene.Game 层：
- 默认：0.3s 淡入黑色 → 切换 → 0.3s 淡出
- 进入战斗：0.4s 圆形擦除（iris wipe）
- 退出战斗：0.3s 圆形收缩
- 过渡期间冻结输入

实现：Game 加 transition 状态机（idle → fadeOut → switch → fadeIn → idle）。Draw 顶层叠加全屏黑色矩形。iris wipe 用 Kage shader。

### 2.2 波次开始演出

当前：toast 提示，无戏剧感。

方案：
- 普通波：屏幕上方滑入 "WAVE 5"（0.3s ease-out），停留 0.8s，0.3s 上滑消失。文字带微弱发光
- Boss 波（每 5 波）：屏幕边缘闪红 2 次 + "WARNING" 脉冲 + 全屏微暗 0.5s → Boss 名称滑入
- 最终波：金色 "FINAL WAVE" + 全屏金色闪光

实现：新建 `render/hud/wave_announce.go`，状态机驱动（slideIn → hold → slideOut）。

### 2.3 胜败画面动画

当前：一行文字 + 静态数字。

**胜利**：
- 背景渐变模糊（radial blur shader）
- "VICTORY" 弹入（0.3s overshoot）
- 1-3 星依次弹入（每颗 0.2s 间隔）+ 金色粒子
- 统计数字逐项计数动画（0.5s/stat）
- 按钮从底部滑入

**失败**：
- 屏幕灰度化（color_grade shader desaturation）
- "DEFEATED" + 屏幕震动
- 统计直接显示（失败时不想等）
- 红色暗角加重

实现：result.go 加 animPhase 状态机。星级从 session stats 计算。

### 2.4 HitStop/慢动作扩展

当前：Boss kill 3 帧 HitStop。

方案：
- Boss kill: 3 帧 HitStop + 0.3s 慢动作（gameSpeed * 0.3）+ 白闪
- 连杀 5+：1 帧 HitStop + "MULTI KILL x5" 文字
- 完美波次：金色闪光 + "PERFECT" toast

## Tier 3: 氛围层

### 3.1 环境粒子

当前：无环境粒子。

方案：利用已有粒子系统：
- 漂浮光点：30-50 个白色微粒，极低速漂移（speed 5-15），alpha 0.15-0.3
- 上升微粒：10-20 个缓慢上升柔光点，像热气升腾
- 颜色跟随关卡主色调（可配置）
- Low 画质下关闭

实现：EmitAmbient(pool, screenW, screenH) 每秒补充粒子。Life 8-12s。

### 3.2 标题画面氛围

当前：纯色 + 2 条线 + 4 角装饰。

方案：
- 环境粒子加大密度（100+ 浮动光点）
- 标题文字呼吸脉冲（scale 1.0 ↔ 1.02，3s 周期）
- 按钮悬停发光
- 底部版本号

### 3.3 氛围光源扩展

当前：动态光照只挂在塔上。

方案：
- 路径入口/出口：常驻红/蓝呼吸光源
- Boss 敌人：自带橙色脉冲光源
- 战灵：专属色光源
- 技能释放：临时高强度闪光（0.2s 衰减）

### 3.4 地图深度感

当前：完全平面。

方案（不需要新美术）：
- 路径投影：路径线下方 2px 偏移画深色半透明副本
- 塔底部阴影：扁椭圆（alpha 0.2，灰色）
- 建塔槽凹陷：内阴影圆环（外浅内深渐变）

## Tier 4: 交互细节

### 4.1 建塔动画

方案：scale 0 → 1.1 → 1.0（0.3s overshoot）+ alpha 0→1 + 白色扩散环 + 金色粒子反向飞入。

### 4.2 卖塔动画

方案：scale 1.0 → 1.2 → 0（0.25s 先膨胀后缩小）+ 金色粒子散射。

### 4.3 升级闪光

方案：白闪 1 帧 + 上射白色粒子 3-5 个 + scale 微弹 + 等级指示环（lv2 单环/lv3 双环/lv4 三环）。

### 4.4 按钮按下反馈

方案：按下 scale 0.95 + 松开 1.0 + 点击波纹 + 不可用按钮抖动拒绝。

### 4.5 状态效果可见性

当前：2.5px 小点不可见。

方案：
- 冰冻：精灵蓝色 tint + 冰晶拖尾粒子
- 灼烧：橙色 tint + 头顶冒火粒子
- 眩晕：头顶旋转星星（3 小圆 120° 间隔）
- 流血：红色滴落粒子
- 保留小点作为最小化指示

## Tier 5: 进阶品质

### 5.1 弹道朝向

方案：atan2(VY, VX) 计算角度，DrawProjectile 旋转几何图形。

### 5.2 塔升级外观

方案（程序化，不需要新精灵）：
- Lv2: scale 1.05 + 底部单环
- Lv3: scale 1.1 + 双环 + 微弱辉光
- Lv4: scale 1.15 + 三环 + 强辉光 + 精灵偏亮

### 5.3 类型化冲击 VFX

方案：
- 火系：橙红扩散 + 火粒子
- 冰系：蓝白扩散 + 冰粒子 + 冰裂纹线条
- 电系：电火花粒子 + ThunderBolt
- 物理系：当前通用冲击环

### 5.4 地形装饰

方案：JSON 配置装饰元素列表。空白格子随机放装饰精灵（石头/草丛/晶体），8-16px，alpha 0.3-0.5。归入 map cache。

### 5.5 Bloom 修复/替代

方案：
- 调查 DrawRectShader crash 根因
- 若无法修复：CPU 端简化 bloom（高亮区域叠加模糊副本）
- 或等 Ebitengine 更新

## 推荐实施顺序

优先做 Tier 1 + Tier 2 前两项（场景过渡 + 波次演出）。这 5 项改动覆盖了玩家最频繁感知的时刻，投入产出比最高。

```
Sprint 1: Tier 1 全部（死亡/命中/射击）+ 场景过渡
Sprint 2: 波次演出 + 胜败动画 + 环境粒子
Sprint 3: Tier 3 剩余 + Tier 4
Sprint 4: Tier 5 按需
```
