# Visual Upgrade Roadmap — 未完成项

## 一、Kage Shader 效果

### 1. Bloom 发光（已有 pipeline，待修复启用）
- 塔攻击时弹射物发光拖尾
- Boss 出场全屏 bloom 脉冲
- 战灵技能释放时局部 bloom
- **状态**：Pipeline 已实现（bloom_extract/blur/combine），但 DrawRectShader 在 Ebitengine v2.9.9 有 runtime crash，`BloomEnabled` 默认 false。待 Ebitengine 升级后启用。

### 2. 屏幕后处理（部分未完成）
- **波纹扭曲**：冰冻塔命中时局部波纹效果
- **昼夜循环色调**：暖色→冷色渐变（受伤红闪已实现）

### 3. 粒子系统（部分未完成）
- 火焰塔：持续火焰粒子
- 冰冻塔：雪花飘落
- **已有**：DeathBurst/MuzzleFlash/Fire/Ice/GoldCollect/ElectricSparks 预设

## 三、HUD / UI 提升

### 8. 过渡动画（部分未完成）
- 波次开始：屏幕上方滑入 "Wave 3" 大字，1s 后滑出
- 建塔成功：塔位闪烁 + 放大回弹动画
- 卖塔：金币数字飘升动画
- **已有**：场景淡入淡出（0.3s fade-to-black）

### 9. 伤害数字（部分未完成）
- 暴击红色 / 治疗绿色区分

### 10. 小地图 / 战场概览
- 右下角半透明小地图，显示敌人位置（红点）和塔位置（蓝点）
- 点击小地图可以快速定位

### 11. 技能释放 UI
- 战灵技能释放时，屏幕边缘闪光提示

## 四、音视觉联动

### 12. 节奏感（部分未完成）
- 攻速快的塔配合短促音效 + 微闪光
- 连杀提示（3/5/10 连杀文字 + 音效升调）
- **已有**：Boss 受击 hitStop

## 五、性能优化

### 13. 批量渲染
- 将同类精灵合并为单次 DrawImage 调用（Sprite Batch）
- 敌人/弹射物数量大时避免逐个 Draw
- **实现**：`ebiten.DrawTriangles` + 纹理图集
