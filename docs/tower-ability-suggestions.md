# 炮塔能力搭配建议

## 机制兼容性说明

| 攻击方式 | OnHit 能力 | OnTick 能力 | 说明 |
|---------|-----------|------------|------|
| projectile | 可用 | 可用 | 弹射物命中走完整能力链 |
| laser | 可用 | 可用 | 即时命中，等同 projectile |
| wideBeam | 可用 | 可用 | 每个被光束扫到的敌人触发 OnHit |
| charge | 可用 | 可用 | 蓄力弹命中触发 OnHit |
| scatter | **不可用** | 可用 | 散射弹走 ScatterGroup 合并，跳过 OnHit |
| spin_aoe | **不可用** | 可用 | 直接扣血，不经过弹射物系统 |

## 建议搭配

### laser 激光炮台 — 远程狙击手
- 定位：超远射程单体点杀，打高威胁目标
- 攻击方式：laser（即时命中），OnHit 能力**可用**

| 建议能力 | 理由 | 协作分析 |
|---------|------|---------|
| distanceDamage | 距离越远伤害越高，与200射程完美配合 | |
| executionBonus | 残血斩杀，配合高单发伤害一击终结 | |
| crit | 暴击爆发，点杀 Boss 时效果拔群 | |

### en-04 光束照射塔 — 持续群伤
- 定位：宽光束同时命中多敌人，持续输出
- 攻击方式：wideBeam（多目标即时），OnHit 能力**可用**（每个被命中敌人独立触发）

| 建议能力 | 理由 | 协作分析 |
|---------|------|---------|
| burn | 灼烧所有被光束扫到的敌人，群体持续伤害 | |
| onHitSlow | 群体减速，配合宽光束一次减速整排 | |
| stackDamage | 光束持续照射同一敌人叠加伤害，打前排肉盾 | |

### en-05 能量散弹塔 — 扇面压制
- 定位：锥形穿透弹丸，面积封锁
- 攻击方式：scatter（穿透弹丸），OnHit **不可用**，只能用 OnTick 能力

| 建议能力 | 理由 | 协作分析 |
|---------|------|---------|
| poisonZone | 射程内持续毒伤，配合散弹的面积压制 | |
| silenceZone | 射程内沉默+减速，增强控制能力 | |
| damageUpAura | 给周围友方塔加伤害，散弹塔本身靠散弹输出 | |

### wl-02 旋风刃 — 近战绞肉机
- 定位：超近距离（80px）旋转切割，中心150%伤害
- 攻击方式：spin_aoe（直接扣血），OnHit **不可用**，只能用 OnTick 能力

| 建议能力 | 理由 | 协作分析 |
|---------|------|---------|
| curseZone | %HP削减，近战范围与旋风完全重合，打肉盾 | |
| soloBoost | 旋风刃常放在路口前排，周围少有其他塔，孤立加成收益高 | |
| poisonZone | 毒伤叠加旋风物理伤害，双重 AoE | |
