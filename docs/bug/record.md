## 缺失的功能性 UI

1. **战灵选择界面** — JS 版有完整的战灵列表 + 技能描述 + 属性面板 + 选择按钮
2. **波次预览** — JS 版左下角显示下一波敌人组成
3. **事件选择弹窗** — JS 版弹出选项面板，Go 版 `stage.go` 中注释 `// TODO: event selection UI`
4. **速度控制** — JS 版支持 x1/x2 切换
5. **建塔/造怪/开波按钮** — JS 版顶部有操作按钮组

## 疑似 Bug

### B1: 塔 SVG 未渲染

**现象**: 截图(img.png)中塔显示为彩色方块而非 SVG 模型，但 `assets/towers/` 下有 12 个 core SVG 文件。

**可能原因**:
- `TowerRenderer.loadTowerImage` 的 asset 路径拼接与实际文件路径不匹配
- `embed.FS` 未正确包含 SVG 资源
- SVG 解析失败（oksvg 对某些 SVG 特性不支持）但 fallback 静默回退

**排查方向**: 在 `loadTowerImage` 加日志，确认 SVG 是否被读取、解析是否成功。

### B2: 敌人 SVG 未渲染

**现象**: 截图中敌人全部显示为红圆点，但 `assets/enemies/` 下有 75 个 SVG。

**可能原因**: 同 B1，另外 `draw_enemy.go` 中 `archetype == "" || archetype == "normal"` 会跳过 SVG 直接用 fallback，如果配置中 archetype 字段缺失则全部回退。

## 优先级建议

```
P0 (阻塞级): 排查 SVG 加载问题 — 资源已有，管线已有，可能只是路径/配置问题
P1 (高优先): 字体系统 — 从 debug font 升级到自定义字体 + 中文支持，这是最大观感瓶颈
P2 (高优先): 地图渲染 — 背景/路径/建塔位视觉升级
P3 (中优先): HUD 美化 — 顶栏/建造菜单/信息面板
P4 (中优先): 补齐缺失 UI — 战灵选择 > 事件选择 > 波次预览 > 速度控制
P5 (低优先): 弹道/英雄/战灵视觉升级
```
