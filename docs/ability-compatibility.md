# 能力兼容性分析

更新日期：2026-03-29

## 攻击方式与能力触发机制

| 攻击方式 | 代表塔 | OnHit 能力 | OnTick 能力 | 触发特点 |
|---------|--------|-----------|------------|---------|
| projectile | 冰冻/电磁/猎手 | 可用 | 可用 | 单弹命中触发一次 |
| laser | 激光 | 可用 | 可用 | 即时命中触发一次 |
| wideBeam | 光束照射 | 可用 | 可用 | 每个被光束扫到的敌人触发一次 |
| charge | 湮灭射线 | 可用 | 可用 | 蓄力弹命中触发一次 |
| scatter | 能量散弹 | 可用（合并后） | 可用 | 同敌人多弹合并后触发一次，基于合并伤害 |
| spin_aoe | 旋风刃 | 可用（每敌） | 可用 | 每个攻击周期对范围内每个敌人各触发一次 |

## OnHit 能力 × 散弹/旋风 兼容性矩阵

### 可放心配（9个）

| 能力 | 散弹表现 | 旋风表现 |
|------|---------|---------|
| crit | 合并后整体暴击判定 | 每敌独立暴击判定 |
| flatDamage | 合并后附加一次固伤 | 每敌附加固伤 |
| executionBonus | 合并后判定低血斩杀 | 每敌独立判定低血 |
| percentHpMinor | 合并后附加一次%HP伤害 | 每敌附加%HP伤害 |
| onHitSlow | 所有命中敌人被减速 | 范围内全部减速 |
| stun | 每敌独立概率眩晕 | 每敌独立概率眩晕 |
| bleedDot | 所有命中敌人流血 | 范围内全部流血（每周期刷新计时器） |
| burn | 所有命中敌人灼烧 | 范围内全部灼烧（每周期刷新计时器） |
| buffPurge | 命中即剥离护盾 | 范围内全部剥盾 |

### 有条件配（3个）

| 能力 | 散弹 | 旋风 | 注意事项 |
|------|------|------|---------|
| stackDamage | 可用，每敌独立叠层 | 可用，每敌独立叠层 | AoE 打多敌人时叠层慢（每周期仅+1），更适合单体塔 |
| distanceDamage | 可用，远敌伤害高 | **不建议** | 旋风80px范围内距离差异极小，几乎无收益 |
| deathMark | 可用，少量标记 | **谨慎** | 旋风范围内全标记，击杀一个引发链式爆炸，可能过于强力或雪崩 |

### 不应配（3个）

| 能力 | 散弹问题 | 旋风问题 | 原因 |
|------|---------|---------|------|
| bounce | 合成弹射物 Speed=0 Radius=0 | 每敌都弹射，弹射弹异常 | 非弹射物路径生成的合成 Projectile 缺少物理参数，弹射弹无法正常飞行 |
| splash | 散弹穿透+溅射双重 AoE 叠加 | 旋风已是 AoE，溅射完全冗余 | 散弹过度叠加伤害；旋风溅射目标已在 AoE 范围内，无额外效果 |
| percentHpDamage | 所有新敌人同时触发"首击" | 范围内新敌人全触发 | "切换目标首击"语义对 AoE 无意义，变成"遇到新敌就触发"，失去猎手印记的定位 |

## OnTick 能力兼容性

所有 OnTick 能力（光环/区域/经济）天然与所有攻击方式兼容，不依赖弹射物系统：

| 能力 | 类型 | 任意塔可配 |
|------|------|-----------|
| damageUpAura | aura | 是 |
| attackSpeedAura | aura | 是 |
| rangeAura | aura | 是 |
| critAura | aura | 是 |
| soloBoost | aura | 是 |
| poisonZone | zone | 是 |
| silenceZone | zone | 是 |
| curseZone | zone | 是 |
| goldPassive | economy | 是 |

## Pipeline 层特殊能力

| 能力 | 限制 | 说明 |
|------|------|------|
| multiTarget | 仅标准冷却路径 | projectile/laser/wideBeam/charge 可用；spin_aoe/scatter 自管理，不走 multiTarget |
| shieldIgnore | 仅弹射物路径 | scatter 合并段未检查 shieldIgnore，如需配散弹塔需补充实现 |
| chargeShot | 仅 charge 攻击方式 | 倍率在 handler_charge.Fire 中应用，其他攻击方式无效 |
