# 如何手动测试游戏

> 面向 QA 和策划，指导如何通过实际游玩发现 Bug 和优化点。

---

## 一、环境准备

### 1.1 启动游戏

```bash
# 桌面版（直接运行，最快启动）
make run

# WASM 网页版
make build-wasm
# 然后浏览器打开 dist/web/index.html
```

### 1.2 选择测试地图

| 地图 | 用途 | 说明 |
|------|------|------|
| `map_test` | 功能验证 | 紧凑 S 形路径，快速迭代 |
| `map_dummy` | DPS 测试 | 直线路径，两侧密集塔位，适合测伤害 |
| `map_01` | 新手体验 | S 形 12 波，验证新手引导和基础流程 |
| `map_07` | 极限压力 | 极少塔位 22 波，验证高压下的平衡性 |
| `map_08` | Boss 测试 | 四面出怪 25 波，验证 Boss 机制 |

### 1.3 选择游戏模式

| 模式 | 适合测试 | 特点 |
|------|---------|------|
| **test**（测试模式） | 功能调试 | 永不失败、自动开波 |
| **campaign**（战役） | 核心体验 | 标准流程，12 波通关 |
| **endless**（无尽） | 后期平衡 | 无上限，测后期数值膨胀 |
| **boss_rush** | Boss 平衡 | 每波 1 Boss，测 Boss 机制 |
| **timed** | 防守压力 | 300 秒限时，测极限生存 |
| **challenge** | 特殊规则 | 限制条件下的可行性 |
| **autoplay** | 自动回归 | 无失败+自动开波，跑基准数据 |

### 1.4 难度选择

| 难度 | HP 倍率 | 速度倍率 | 初始金 | 适合测试 |
|------|---------|---------|--------|---------|
| easy | 0.7x | 0.85x | 180 | 新手体验、基础功能 |
| normal | 1x | 1x | 120 | 标准平衡、核心流程 |
| hard | 1.4x | 1.15x | 100 | 数值极限、策略深度 |
| extreme | 2x | 1.3x | 80 | 极限挑战、破产边界 |

## 二、核心测试维度

### 2.1 建塔与经济

**测什么：** 建/卖/升级流程、金币收支、经济节奏

**测试步骤：**
1. 开局只有 120 金，第一座塔 50 金 → 验证能否建 2 座塔起步
2. 卖塔 → 验证返还金币 = 花费 × 0.7（70% 回收率）
3. 快速连点建塔 → 是否能建到负金币（不应该）
4. 波次奖金 = 12 + wave×4 → 第 1 波拿 16 金，第 12 波拿 60 金，是否正确
5. 完美通波（0 泄漏）额外奖金 = 8 + wave×2
6. 难度 hard 下奖金只有 0.8 倍 → 验证奖励缩放

**常见 Bug：**
- 快速点击建了两座塔但只扣一次钱
- 卖塔后金币显示和实际不一致
- 波次奖金没有乘以难度倍率

### 2.2 战斗与伤害

**测什么：** 塔攻击、弹道、伤害数值、特殊效果

**测试步骤：**
1. 用 `map_dummy`（直线靶场）单塔打单怪 → 看 DPS 是否符合配置
2. 切换塔模式（均衡/速射/重炮） → 攻速和伤害是否有变化
3. 多塔同时攻击同一个敌人 → 伤害是否正确叠加
4. 溅射塔打密集怪群 → 溅射范围和伤害衰减是否正确
5. 激光塔持续照射 → 是否正确消耗持续时间
6. 弹射塔射击 → 弹射目标数和伤害衰减是否正确

**关键数值校验：**
- Boss 伤害上限 = Boss 最大 HP × 5%（`bossDamageCapRatio: 0.05`）
- 减速上限 = 70%（`slowCap: 0.30`，即最低速度为 30%）
- 护甲计算：每 1 点护甲减 1% 伤害（`armorDivisor: 100`），最大 50 护甲
- 负护甲：每 1 点增 1% 伤害（`negativeAmplifyPerPoint: 0.01`），最大放大 3 倍

**常见 Bug：**
- 弹道发射但没有命中（碰撞检测失败）
- 塔换目标时第一发打空（目标已死但弹道已发射）
- DOT（持续伤害）在敌人死亡后仍在计算
- Boss 伤害上限没生效，一发秒杀

### 2.3 敌人行为

**测什么：** 敌人移动、特殊能力、Boss 机制

**测试步骤：**
1. 普通怪沿路径行走 → 是否贴合路径、不穿墙
2. runner（跑者）→ 速度明显快于普通怪
3. tank（坦克）→ 血量明显高于普通怪
4. splitter（分裂怪）死亡 → 是否正确分裂出小怪
5. stealth（隐身怪）→ 是否正确隐身、溅射/AoE 是否能揭隐
6. medic（奶妈）→ 是否正确治疗周围友方
7. teleporter（传送兵）→ 是否周期跳跃前进
8. mirror（镜像兵）→ 首次受伤是否复制自身
9. boss 出场 → 特殊机制是否正确触发

**关键 Boss 检查清单：**

| Boss | 核心机制 | 验证要点 |
|------|---------|---------|
| boss-iron | 30 甲 + 10% 伤害上限 | 破甲后伤害是否提升 |
| boss-storm | 传送 + 免减速 | 冰冻塔是否无效 |
| boss-grove | 3%/s 回血 + 治疗光环 | DPS 是否能压过回复 |
| boss-legion | 光环加速加甲 + 召唤 | 小怪是否正确获得增益 |
| boss-shadow | 受击隐身 + 反射攻速 | 多塔攻击是否分散降速 |
| boss-omega | 40 甲 + 4% 上限 + 弱点轮换 | 弱点切换是否有视觉提示 |

**常见 Bug：**
- 敌人在路径拐角处卡住或穿越障碍
- 分裂怪的子怪没有继承正确的路径进度
- Boss 的伤害上限在 DOT 伤害下失效
- 隐身怪被非揭隐手段击中

### 2.4 状态效果与协同

**测什么：** 减速/眩晕/灼烧/流血/中毒/护甲削减等

**测试步骤：**
1. 冰冻塔 → 敌人速度是否降低、降到下限后是否不再叠加
2. 眩晕 → 敌人是否完全停止移动
3. steadfast（稳行者）→ 是否免疫减速
4. ironwill（铁意兵）→ 是否免疫眩晕
5. 多个减速效果叠加 → 速度不低于 30%（slowCap）
6. 灼烧 + 流血 → DOT 是否独立计时（burn 0.5s/tick, bleed 0.5s/tick, poison 1s/tick）
7. 负护甲 → 受到的伤害是否放大

**常见 Bug：**
- 减速效果结束后速度没有恢复
- 多个 DOT 只有一个在生效
- 免疫效果只免疫了第一次，后续仍被控制

### 2.5 波次系统

**测什么：** 出怪节奏、波次难度递增、特殊波次

**测试步骤：**
1. 第 1 波 → 8 只普通怪（base 6 + perWave 2×1）
2. 每 4 波出精英 → 第 4/8/12 波是否有 elite
3. 波次间歇 10 秒（战役）→ 是否准确
4. 怪物 HP = hpBase(52) + hpPerWave(21) × wave → 手动验证
5. 第 5 波后有额外 HP 加成（lateHpBonusPerWave: 12.5%/波）→ 后期怪是否明显变肉
6. 出怪间隔：base 0.92s，每波递减 3%，最低 0.18s → 后期是否变密

**常见 Bug：**
- 最后一波清完但游戏没有判定胜利
- 波次间歇中敌人提前出现
- 后期出怪间隔降到 0 导致瞬间涌出

### 2.6 守护者（Warden）系统

**测什么：** 守护者选择、能力效果、成长

**测试步骤：**
1. 开局选守护者 → 是否正确展示选项和描述
2. 守护者放置 → 是否出现在指定位置
3. 守护者攻击 → 伤害和攻速是否符合配置
4. 波次通关后守护者升级 → 属性是否正确提升
5. 守护者特殊能力 → 是否正确触发和生效

## 三、专项测试场景

### 3.1 新手体验测试（策划重点）

**目标：** 模拟零基础玩家首次游玩

1. 选 easy + map_01
2. 不看任何教程说明，凭直觉操作
3. 记录：
   - 第一次建塔花了多久？界面是否清晰？
   - 第一波怪泄漏了几只？新手是否能活过前 3 波？
   - 金币花完后是否感到焦虑？经济节奏是否合理？
   - 到第几波开始觉得有难度？
4. 全程不查配置，只靠游戏内信息
5. 重点关注：**哪里让人困惑、哪里让人无聊、哪里让人沮丧**

### 3.2 极限平衡测试

**目标：** 找到数值崩溃点

1. **最低配置通关测试**
   - extreme 难度 + map_07（极限窄道）
   - 记录最少塔数通关的布阵方案
   - 如果无法通关 → 可能需要调数值

2. **最强配置碾压测试**
   - easy 难度 + map_01
   - 尽量建满塔，看最终波次剩余生命
   - 如果 20 命没掉 → 太简单了

3. **经济断档测试**
   - normal + map_03（铁壁防线）
   - 故意不卖塔，看经济是否会卡死
   - 记录哪一波开始攒不出下一座塔

4. **后期数值膨胀测试**
   - endless 模式 + map_06
   - 记录第几波开始漏怪、第几波彻底崩盘
   - 观察 DPS 增长 vs 怪物 HP 增长是否平衡

### 3.3 Boss 专项测试

1. boss_rush 模式
2. 逐个 Boss 记录：
   - 初见是否能看懂 Boss 机制？（视觉提示是否充分）
   - 没有针对性布阵时能否过 Boss？
   - 有针对性布阵时 Boss 是否太容易？
3. 特别关注 boss-omega（终焉审判）：弱点轮换机制是否直观

### 3.4 多路径 / 多入口测试

1. map_02（双入口交叉）→ 资源分配是否够用
2. map_05（双线战场）→ 上下两路是否平衡
3. map_08（四面出怪）→ 是否有死角盲区

### 3.5 特殊敌人组合测试

以下组合特别容易出 Bug，需要专项验证：

| 组合 | 关注点 |
|------|--------|
| medic + tank | 奶妈能否撑住坦克到漏怪 |
| stealth + runner | 隐身快怪能否被及时发现 |
| splitter + swarm | 分裂后数量爆炸是否导致卡顿 |
| banner + armored | 旗手加甲 + 自带高甲是否无敌 |
| mirror + mirror | 镜像互相复制是否死循环 |
| teleporter + steadfast | 传送+免减速是否无解 |

## 四、视觉与 UI 测试

### 4.1 渲染正确性

- 塔模型是否正确显示（无缺失、无错位）
- 弹道轨迹是否从塔出发到敌人身上
- 溅射范围是否有视觉反馈
- 敌人血条是否准确反映剩余 HP
- 状态效果图标是否正确显示（减速、灼烧、中毒等）
- 死亡动画是否正确播放

### 4.2 HUD 与交互

- 金币/生命/波次数字是否实时更新
- 建塔面板是否正确显示可建造的塔（金币不足时灰显）
- 塔选中后信息面板是否准确
- 暂停/继续按钮是否正常工作
- 加速按钮是否正确切换速度

### 4.3 性能观察

- 大量敌人（30+）同屏是否掉帧
- 大量弹道（溅射/弹射同时触发）是否卡顿
- 分裂怪连锁分裂是否导致帧率暴跌
- 长时间运行（endless 50 波+）是否有内存泄漏迹象

```

1. ...
2. ...
3. ...
**预期行为：** ...
**实际行为：** ...
**严重程度：** P0(崩溃) / P1(功能不可用) / P2(数值错误) / P3(体验问题)
```

## 六、测试检查清单（每次构建后快速过一遍）

### 冒烟测试（5 分钟）

- [ ] 游戏能正常启动，主菜单显示
- [ ] 选择战役模式 + map_01 能进入游戏
- [ ] 能建塔、能卖塔、金币正确扣除/返还
- [ ] 第 1 波怪正常出现并沿路径行走
- [ ] 塔能攻击并杀死敌人
- [ ] 通过第 1 波后有波次奖金
- [ ] 暂停/继续/加速正常工作
- [ ] 通关或死亡后显示结算画面

### 功能回归（15 分钟）

- [ ] 4 种难度都能正常进入
- [ ] 至少 3 张不同地图能正常加载
- [ ] 塔的 3 种模式（均衡/速射/重炮）切换正常
- [ ] 守护者选择和放置正常
- [ ] Boss 出场和特殊机制正常
- [ ] endless 模式能超过 15 波不崩溃
- [ ] 测试模式永不失败

### 平衡验收（30 分钟）

- [ ] normal + map_01 通关体验顺畅，无明显卡点
- [ ] hard + map_03 有挑战但可通关
- [ ] extreme + map_07 非常困难但理论可通
- [ ] 各类特殊敌人机制都有发挥空间（不是摆设）
- [ ] Boss 有压迫感但不是无解
- [ ] 金币经济不会在中期断档

## 七、自动化辅助

手动测试发现的问题，确认后应转化为自动化测试：

```bash
# Go 单元测试（最快反馈）
make test

# 带覆盖率
make test-cover

# 完整 CI 检查（lint + test）
make check-all

# 自动对局基准测试
go run ./cmd/autoplay/
```

**配置查看工具：**
```bash
# 只读配置查看器（浏览器）
make preview
# 访问 http://localhost:8080/web/config-viewer/
```

## 八、策划专项：「感觉」测试

数值正确不等于体验好。以下是策划需要凭感觉判断的维度：

| 维度 | 好的感觉 | 坏的感觉 |
|------|---------|---------|
| **节奏** | 波次间有喘息但不无聊 | 等太久 or 喘不过气 |
| **压力曲线** | 前松后紧，逐渐升温 | 一直太难 or 一直太简单 |
| **经济** | 总是差一点钱，需要取舍 | 钱太多随便建 or 钱太少什么都做不了 |
| **击杀反馈** | 打到怪有反馈感、击杀有成就感 | 打了但没感觉，或者怪莫名就死了 |
| **Boss** | 看到 Boss 紧张，打过后兴奋 | Boss 和小怪没区别 or Boss 无解 |
| **特殊怪** | 看到提示会调整策略 | 没注意到特殊怪就死了 or 特殊怪没影响 |
| **失败** | "差一点就过了，再来一次" | "完全不知道怎么过" or "运气不好" |

记录方式：每次测完写 1-2 句话描述感受，比如：
> "第 6 波突然来一群 armored 感觉很突然，前面 5 波没有任何铺垫。"
> "boss-storm 的传送太频繁了，刚布好阵就跳走了，非常沮丧。"
