最小上架路径（按顺序）

1. Android 构建流水线（Makefile android target → APK）
2. 广告 SDK 接入（AdMob interstitial + rewarded）
3. 广告触发点（关卡间插屏 + 失败激励视频）
4. 隐私合规（隐私政策 URL + GDPR 弹窗）
5. 应用图标 + 商店截图
6. 商店元数据 + 上传

核心结论：游戏玩法和技术完成度很高，主要差距在商业化基础设施（广告 SDK + Android 打包 + 商店合规）。纯开发工作量不大，但需要你来决定广告策略和商业模式。
