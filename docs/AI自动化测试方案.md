# AI 自动化测试方案

> 逐条对应《如何手动测试》中的每个维度，说明 AI 如何替代或超越人工测试。

---

## 总体思路

人工测试的核心价值分三层：

| 层级 | 人做什么 | AI 怎么替代 |
|------|---------|------------|
| **执行层** | 启动游戏、建塔、看数字 | AutoPlay + 策略引擎，速度 10x+，不犯操作错误 |
| **判断层** | 判断"这是 Bug"还是"设计如此" | 13+ 异常检测器 + 配置契约断言 + 回归 Sim |
| **感知层** | "手感不对"、"节奏太快" | 数据指标量化 + LLM 语义分析 + 阈值告警 |

前两层 AI 可以完全超越人工（速度、覆盖率、一致性）。第三层需要 AI 从数据中推断"感觉"，是核心难点。

## 一、环境准备 → 全自动化

### 人工做法
手动选模式/地图/难度，每次只能测一种组合。

### AI 做法

**已有能力：** `autoplay --sweep` 自动生成 65+ 测试用例的覆盖矩阵。

```bash
# 一键全量扫描：8地图 × 4难度 × 5守护者 × 6策略
go run ./cmd/autoplay/ --sweep

# 针对性回归：只跑上轮失败场景
go run ./cmd/autoplay/ --targeted
```

**超越人工的点：**
- 人一天测 10 种组合已经极限，AI 一次跑 65+ 种组合，约 15 分钟
- 覆盖矩阵保证每个（地图, 难度）、（地图, 守护者）、（策略, 难度）对至少出现一次
- 多进程隔离（Ebitengine 限制每进程一个实例），自动 fork 子进程

**待建设：**
- [ ] CI 集成（Linux 需 Xvfb 虚拟帧缓冲运行 Ebitengine）
- [ ] 并行执行多个子进程，从串行 ~15min 降到 ~3min

## 三、专项测试场景 → AI 策略对照

### 3.1 新手体验 → AI 模拟"笨玩家"

**人工做法：** 策划假装自己不会玩，凭直觉操作。

**AI 做法：**

```
Random 策略（已有）：2%/帧建塔，0.5%/帧升级，0.1%/帧卖塔
                    完全随机 = 最差玩家
```

**量化"新手体验"指标：**

| 指标 | 采集方式 | 判定标准 |
|------|---------|---------|
| 前 3 波存活率 | Random 策略跑 100 次 | >=95% 的 run 活过第 3 波 |
| 首塔时间 | 录制器记录第 1 座塔的帧号 | easy 模式 <300 帧（5s） |
| 经济窒息波次 | 金币曲线 = 0 持续 >15s 的首次出现波次 | 不应早于第 4 波 |
| 总泄漏比 | 泄漏数 / 总怪数 | easy 模式 random 策略 <50% |

**超越人工：** 人只能扮演 1 种"笨玩家"，AI 可以跑 100 种随机行为分布，得到统计置信区间。

**待建设：**
- [ ] "新手模拟"策略：延迟建塔（前 5 秒不操作）、只建最便宜的塔、不卖塔
- [ ] 新手体验报告：自动生成"第 N 波开始漏怪"、"第 N 波经济断档"统计图

### 3.2 极限平衡 → AI 暴力搜索

**人工做法：** 策划用最难配置试着通关，凭经验判断。

**AI 做法：**

**超越人工：**

## 七、策划「感觉」测试 → AI 量化代理指标

这是最难自动化的部分。核心思路：**把主观感受翻译成可度量的数据指标**。

| 感觉维度 | 量化代理指标 | 采集方式 | 告警条件 |
|---------|------------|---------|---------|
| **节奏** | 波间空闲时间 / 战斗时间比值 | 录制器时间戳 | ratio > 3（太无聊）或 < 0.3（喘不过气） |
| **压力曲线** | 每波泄漏数的趋势斜率 | 录制器 per-wave stats | 前 3 波就有泄漏（太难）或 最后 3 波 0 泄漏（太简单） |
| **经济** | 金币储备 / 下一塔成本 比值 | 每波结束时快照 | ratio > 5（太富）或连续 3 波 ratio < 0.5（太穷） |
| **击杀反馈** | 平均击杀间隔（秒） | 录制器击杀时间戳 | interval > 10s（无聊）或 < 0.1s（刷怪感） |
| **Boss 压力** | Boss 存活时间 / 波次总时间 | Boss 出生→死亡帧差 | < 5s（太弱）或 > 60s（可能无解） |
| **特殊怪影响** | 特殊怪存活时间 vs 普通怪 | archetype-level 统计 | 差异 < 10%（机制形同虚设） |
| **失败感** | 最终生命 / 初始生命 | 录制器 final stats | 无生命损耗 = 碾压；瞬间 0 命 = 无望 |

### LLM 辅助"感觉"分析
