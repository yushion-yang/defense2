# SoundFont Files

SF2 files are not tracked in git (too large). Download manually:

## TimGM6mb (recommended, ~6MB)

```bash
curl -L -o TimGM6mb.sf2 \
  "https://sourceforge.net/p/mscore/code/HEAD/tree/trunk/mscore/share/sound/TimGM6mb.sf2?format=raw"
```

## GeneralUser GS (full quality, ~30MB)

Download from: https://schristiancollins.com/generaluser.php
